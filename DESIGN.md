# FieldTrack Design Notes

- Theme: light, tuned for a bright office environment and long encoding sessions.
- Strategy: restrained color with a deep spruce accent for actions and selected navigation.
- Typography: system UI stack for familiar density and good Windows rendering.
- Layout: fixed desktop side navigation with a compact mobile header; tables scroll horizontally on narrow screens.
- Controls: 10px radius, visible focus ring, semantic status pills, minimal shadow use.
